# SummarizeAI — 유튜브 영상 요약 크롬 확장 앱 설계

**날짜**: 2026-08-15
**상태**: 승인됨 (설계 검토 완료)

## 개요

로컬 LLM(LM Studio)을 사용해 유튜브 영상의 자막을 요약해주는 크롬 확장 앱.
확장 앱 스토어의 LiveWiki를 클론코딩하는 학습 + 개인 사용 목적 프로젝트.

## 요구사항

- **LLM 연동**: LM Studio의 OpenAI 호환 로컬 서버 (`http://localhost:1234/v1`)
- **기능**:
  1. 전체 요약 — 영상 자막을 핵심 내용으로 요약
  2. 타임라인 챕터 요약 — 구간별 제목·요약 + 타임스탬프, 클릭 시 해당 시점으로 이동
  3. 영상 Q&A 채팅 — 영상 내용 기반 자유 질의응답
  4. 번역 지원 — 출력 언어 설정 (영어 영상 → 한국어 요약 등)
- **UI**: 유튜브 watch 페이지 오른쪽에 패널 직접 삽입 (LiveWiki 스타일)
- **스택**: React + TypeScript + Vite + CRXJS (Manifest V3)
- **목표**: 학습용 + 개인 사용. 개발자 모드 로드, 스토어 심사 대응 불필요.

## 아키텍처

```
┌─────────────────────────────────────────────┐
│  유튜브 watch 페이지                          │
│  ┌───────────────────────────────────────┐  │
│  │ 콘텐츠 스크립트 (React, Shadow DOM)     │  │
│  │  - 패널 UI (요약/챕터/채팅 탭)          │  │
│  │  - 자막 추출 (ytInitialPlayerResponse) │  │
│  │  - SPA 네비게이션 감지                  │  │
│  └──────────────┬────────────────────────┘  │
└─────────────────┼───────────────────────────┘
                  │ chrome.runtime Port (스트리밍)
┌─────────────────▼───────────────────────────┐
│  백그라운드 서비스 워커                        │
│  - LM Studio API 클라이언트 (OpenAI 호환)     │
│  - 요약 파이프라인 (청크 분할 → map-reduce)    │
│  - Q&A 채팅 핸들러                            │
└─────────────────┬───────────────────────────┘
                  │ HTTP (host_permissions)
        ┌─────────▼─────────┐
        │ LM Studio          │
        │ localhost:1234     │
        └───────────────────┘
```

### 역할 분담

- **콘텐츠 스크립트**: watch 페이지 감지 → Shadow DOM에 React 패널 마운트(유튜브 CSS와
  충돌 방지) → 자막 추출 → 백그라운드에 작업 요청 → 스트리밍 결과를 UI에 렌더링.
  유튜브는 SPA이므로 `yt-navigate-finish` 이벤트로 영상 전환을 감지하고 패널 상태를 리셋.
- **백그라운드 서비스 워커**: LLM 관련 로직 전부. MV3 `host_permissions`로 localhost
  CORS 문제를 우회. 청크 분할, map-reduce 요약, 챕터 JSON 생성, Q&A 채팅.
- **옵션 페이지**: LM Studio 주소, 모델명, 출력 언어(한국어/영어/자동) 설정.
  `chrome.storage.local`에 저장.

모듈별 단일 책임:

- `llm.ts`: 메시지 배열 → 스트리밍 텍스트
- `pipeline.ts`: 자막 → 요약/챕터/답변

## 데이터 흐름

### 요약 생성

1. 콘텐츠 스크립트가 `yt-navigate-finish`로 watch 페이지 진입 감지, 패널 마운트
2. `ytInitialPlayerResponse`에서 자막 트랙 목록 추출 (한국어 → 영어 → 자동생성 순 우선),
   트랙 URL에 `fmt=json3`을 붙여 fetch → `{start, duration, text}[]`로 정규화
3. "요약" 버튼 클릭 → `chrome.runtime.connect`로 Port를 열고 자막 + 영상 메타 전송
4. 백그라운드가 자막 길이 확인:
   - 모델 컨텍스트 이내면 한 번에 요약
   - 길면 청크 분할 → 각 청크 부분 요약(map) → 부분 요약 통합(reduce)
5. 최종 요약은 스트리밍으로 토큰 단위 Port 전달 → UI 실시간 표시
6. 결과는 영상 ID 키로 `chrome.storage.session`에 캐시 (탭 전환 시 재생성 방지)

### 챕터 생성

자막을 시간 기준(영상 길이의 1/8~1/12 구간)으로 분할, LLM에 각 구간의 제목·한 줄 요약을
JSON으로 요청. `{startTime, title, summary}[]`로 파싱해 렌더링. 클릭 시
`video.currentTime = startTime`으로 점프.

### Q&A 채팅

시스템 프롬프트에 전체 요약 + 자막(길면 절단)을 컨텍스트로 주입, 대화 히스토리 유지,
스트리밍 응답. 영상 전환 시 히스토리 리셋.

### 번역/언어

별도 번역 단계 없이 옵션의 출력 언어를 모든 프롬프트에 "반드시 {언어}로 답하라"로 주입.

## 에러 처리

| 상황 | 처리 |
|---|---|
| LM Studio 서버 미실행 | "LM Studio에 연결할 수 없습니다" + 실행 방법 안내, 패널 상단 연결 상태 표시등 |
| 자막 없는 영상 | "이 영상은 자막이 없어 요약할 수 없습니다" 안내 (음성 인식은 범위 외) |
| 챕터 JSON 파싱 실패 | 1회 재시도, 실패 시 "다시 시도" 버튼 |
| 요약 중 영상 이동 | 진행 중 요청 abort, 패널 상태 리셋 |
| 유튜브 DOM 변경 | 패널 삽입 지점 미발견 시 콘솔 경고 + 미표시 (다른 기능 영향 없음) |

## 테스트 전략

- **단위 테스트 (Vitest)**: 자막 정규화, 청크 분할, 챕터 JSON 파싱, 프롬프트 생성.
  Chrome API는 모킹.
- **수동 검증 체크리스트**:
  1. 짧은 영상 (컨텍스트 이내)
  2. 1시간 이상 긴 영상 (map-reduce 경로)
  3. 자막 없는 영상
  4. LM Studio 꺼진 상태
  5. 영상 간 연속 이동 (SPA 네비게이션)
- E2E는 학습용 범위에서 제외 (YAGNI).

## 범위 외 (Out of Scope)

- 음성 인식 기반 자막 생성 (자막 없는 영상 지원)
- 크롬 웹스토어 출시 대응 (심사, 개인정보처리방침 등)
- 유튜브 외 다른 플랫폼 지원
- 계정/동기화 기능
